# Project Instructions

Read `APP_CONTEXT.md` before writing code — it holds the architecture map and the
non-obvious spreadsheet constraints that are easy to violate silently.

## Documentation Rules
- Always maintain project documentation automatically after completing code changes.
- Append a one-line bullet to the '## Unreleased' section of CHANGELOG.md, under the matching [Added]/[Changed]/[Fixed]/[Removed] block. Keep it to one line — mechanism and reasoning go in the commit message.
- Update APP_CONTEXT.md ONLY if you introduced new folders, external APIs, or global code constraints.
- Complete these documentation updates before finishing your task.
